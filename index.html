QL1 録音シミュレーター

ステージで演奏中の音を、QL1のUSBレコーダーで録音する操作を体験します。まず「演奏の音」として使う音源を選んでください。

Googleドライブの場合は、共有設定を「リンクを知っている全員」にしたファイルのリンクを貼り付けてください。サイト側の制限で読み込めないときは、ファイルをダウンロードして「PCのファイル」から選んでください。

ピアノとストリングス風の合成音（約70秒）です。静かに始まり、後半で大きく盛り上がります。最初の音量だけでゲインを決めると、後半で音割れするかもしれません。

音源が未選択です

音が出ます。ヘッドホンまたはスピーカーの音量に注意してください。

練習メニュー

  1. REC RATE を 192kbps に推奨。押すたびに切り替わります
  2. L に INPUT 11 を選ぶL のボタン → タブを切り替えて探す
  3. R に INPUT 12 を選ぶR のボタンも同様に
  4. GAIN でピークを −10〜−6dB に画面の GAIN をタッチ → TOUCH AND TURN を回す
  5. ● で録音待機REC ボタンが点滅します
  6. ▶❚❚ で録音開始演奏の最後まで録音
  7. ■ で録音停止YPE フォルダに保存されます
  1. MONITOR 画面を開く画面上部の MONITOR ボタン
  2. MONITOR INPUT L に INPUT 11録音と同じように選ぶ
  3. MONITOR INPUT R に INPUT 12
  4. 音が出なければスピーカーのツマミを回す照明室のモニタースピーカー
  5. MONO モードを試すハムノイズが位相キャンセルで消えることも
  1. 「ハムノイズ発生」をオンにする下のトラブル設定。ブーンという音が入ります
  2. スピーカーのツマミを 0 にする抜き差しの前に必ず。壊れることがあります
  3. INPUT 11 のケーブルをエアモニ L へ突起を押しながら抜く → 挿し直す
  4. INPUT 12 のケーブルをエアモニ R へ
  5. スピーカーを戻してノイズが消えたか確認

トラブル設定

ハムノイズは電源由来の「ブーン」という低い雑音（北海道は50Hz）。このシミュレーターでは左右で逆位相に入るため、MONO で聴くと打ち消し合います。
