# 講堂録音シミュレーター（QL1）

講堂の音響卓 Yamaha QL1 での録音手順を、ブラウザ上で体感しながら練習するためのアプリです。

- RECORDER 画面：RECORDER INPUT（INPUT 11 / 12）の選択、GAIN 調整（画面のツマミをタッチ → TOUCH AND TURN ノブで回す）、REC → PLAY で録音、STOP で保存
- MONITOR 画面：MONITOR INPUT、LEVEL、MONO
- 卓の横のモニタースピーカー（音量ツマミ）
- 卓の背後の音響機器架：XLR ケーブルの差し替え（吊りマイク ↔ エアモニ）、ハムノイズのトラブル練習

音源は端末内のファイル、URL、または内蔵のデモ音源を使えます。録音はこのアプリでは WAV で保存されます（実機は MP3）。

練習用の簡易シミュレーターであり、実機の画面・挙動を完全に再現したものではありません。
